# Group company logos

Drop the group company logos here as **WebP** files named after their slug:

```
public/group/number-one-ads.webp
public/group/triple-a-signage.webp
public/group/infobus-advertising.webp
```

Slugs come from `src/data/group.js`. Missing files fall back to a text
wordmark. Recommended: transparent background, ~400px wide, trimmed.
