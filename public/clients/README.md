# Client logos

Drop each client logo here as a **WebP** file named after its slug, e.g.:

```
public/clients/the-chennai-silks.webp
public/clients/thangamayil.webp
```

The slugs are defined in `src/data/clients.js`. Any client without a matching
file automatically shows a clean text wordmark instead — so the site always
looks complete. Recommended: transparent background, ~400px wide, trimmed.
