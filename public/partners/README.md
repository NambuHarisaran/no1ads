# Digital advertising partner logos

Drop platform logos here as **WebP** files named after their slug:

```
public/partners/google.webp
public/partners/meta.webp
public/partners/spotify.webp
public/partners/jiohotstar.webp
```

Slugs come from `src/data/partners.js`. Missing files fall back to a text
wordmark. Use the official brand assets only within the platforms' brand
guidelines. Recommended: transparent background, ~240px wide.
